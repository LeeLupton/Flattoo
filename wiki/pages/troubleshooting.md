| What | Try |
|---|---|
| **Printer does nothing** | Ask Flattoo "the printer isn't working". Then [Fix the printer](fix-printer.html). |
| **Wrong size print** | [Calibration page](calibrate.html). |
| **No Wi-Fi** | Wi-Fi icon → right network? [Internet](internet.html). |
| **An app is frozen** | Wait ten seconds. Then **Alt+F4**. If the window stays, right-click it in the panel → Close. Your other work is unaffected. |
| **Everything is frozen** | Hold the power button ten seconds, start again. Krita keeps a backup of open files; it offers it when you reopen. |
| **Screen is black** | Press a key; the laptop may be asleep. Lid fully open? Plugged in? Hold power ten seconds if nothing helps. |
| **Tablet stopped responding** | Unplug it, plug it back in. |
| **The desktop looks different** | Open **Looks** and pick Studio Dark. If the setup is locked, log out and back in. |
| **Running slow, disk full** | Ask Flattoo "free up space". |
| **Something changed after an update** | Pick yesterday's version at the boot menu. [Updates](updates.html). |
| **Lost a file** | Files → search box, top right. Scans are in Documents, phone photos in Downloads. |

Still stuck: tell Lee what you did, what you expected, what happened. "When did it last update" in Ask Flattoo gives the version to mention.
