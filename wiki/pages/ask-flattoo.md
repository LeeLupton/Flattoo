Click the speech bubble next to the menu, or press **Super+Space**. Type what you want the way you would say it:

| You type | What happens |
|---|---|
| *something like Microsoft Paint* | Shows the drawing apps that fit this laptop and which are already here. Pick one → Open or Install. |
| *photoshop* | Krita and GIMP, the two that cover that ground. |
| *install pinta* | Asks "Install Pinta?", installs it, tells you it is in the menu. |
| *update now* | Installs updates now (they also arrive every night by themselves). |
| *the printer isn't working* | Runs Fix Stencil Printer. |
| *prints too small* | Prints the calibration page. |
| *free up space* | Shows free space, offers to clean up. |
| *dark mode*, *bigger text* | Opens Looks. |
| *how do I scan a sketch* | Opens the page of this wiki that explains it. |
| *what can you do* | The full list. |

It always **asks before changing anything**, in a dialog that says what will happen. "Not now" is always an option.

## What it will not do

It is not a chat window and it does not run commands. It knows a fixed set of jobs — install or remove an app from a curated list, open things, update, fix the printer, clean up disk space, Wi-Fi, Bluetooth, battery, looks, layouts, lock — and for anything else it says so and shows the list. That is on purpose: nothing you type into it can break the laptop.

## When it says "ask Lee"

That means the thing you want is not one of its jobs. Lee can add apps to the list or change the setup from his side; it lands on the laptop the next night.
