Tap the speech bubble next to the menu (or press **Super+Space**). A sheet opens with the things people ask most — **Fix the stencil printer, Print a stencil, Show a client my work, Dark mode, Change the look, Add an app, Update now, Free up space, Wi-Fi, Bluetooth, Battery, Portfolio, My profile, Shop display, Night look, Help, Lock/sleep/turn off** — one tap each. Nothing to type.

The last row, **Type something else…**, opens a text box for anything not on the sheet; the on-screen keyboard appears with it. With voice switched on there is also **Say it**: tap, speak, and it repeats what it heard before doing anything. Speech is understood on the laptop itself; nothing is sent anywhere.

Typed or spoken, say it the way you would say it:

| You say | What happens |
|---|---|
| *something like Microsoft Paint* | Shows the drawing apps that fit this laptop and which are already here. Pick one → Open or Install. |
| *photoshop* | Krita and GIMP, the two that cover that ground. |
| *install pinta* | Asks "Install Pinta?", installs it, tells you it is in the menu. |
| *update now* | Installs updates now (they also arrive every night by themselves). |
| *the printer isn't working* | Runs Fix Stencil Printer. |
| *prints too small* | Prints the calibration page. |
| *free up space* | Shows free space, offers to clean up. |
| *the neon look*, *sakura*, *dark mode* | Switches the look (or its dark twin) right away; *bigger text* opens Looks. |
| *dark mode at 9pm* | The automatic night look. |
| *show a client my work* | Your portfolio fills the screen; Done locks the laptop. |
| *effects off* | Rounded corners, shadows and animations off (the laptop feels quicker). |
| *turn off* | The power sheet. |
| *make a portfolio* | Builds a gallery folder from your finished-work photos — nothing uploaded. [What it offers](assist.html). |
| *my resume*, *add fine line to my skills* | Your artist profile, rendered to a résumé and bio. |
| *how do I get more clients* | The exposure checklist. |
| *how do I scan a sketch* | Opens the page of this wiki that explains it. |
| *what can you do* | The full list. |

It always **asks before changing anything**, in a dialog that says what will happen. "Not now" is always an option.

## What it will not do

It is not a chat window and it does not run commands. It knows a fixed set of jobs — install or remove an app from a curated list, open things, update, fix the printer, clean up disk space, Wi-Fi, Bluetooth, battery, looks, layouts, lock — and for anything else it says so and shows the list. That is on purpose: nothing you type into it can break the laptop.

## When it says "ask Lee"

That means the thing you want is not one of its jobs. Lee can add apps to the list or change the setup from his side; it lands on the laptop the next night.
