The **Super** key is the one with the window logo, left of the space bar.

| Keys | Does |
|---|---|
| **Super** | The app grid (Home looks) or the menu (other looks) |
| **Super + Space** | Ask Flattoo |
| **Super + P** | Print as Stencil |
| **Super + L** | Layouts |
| **Super + K** | Krita |
| **Super + E** | Files |
| **Print Screen** | Screenshot (saved to Pictures, or copied) |
| **Alt + Tab** | Switch between open windows |
| **Alt + F4** | Close the window |
| **Ctrl + Alt + L** | Lock the screen |

Inside Krita the usual ones apply: **B** brush, **E** eraser, **Ctrl+Z** undo, **M** mirror the canvas view, **Ctrl+Shift+S** save as.

Looks can change these; each look shows its own in **Settings → Keyboard**.
